# дз-3: логистическая регрессия и streamlit

решение находится в `HW3_MMDA.ipynb`, приложение - в папке `wine_app/`

проверено на python 3.12.14. запуск из корня репозитория:

```bash
python -m pip install -r wine_app/requirements.txt
python -m streamlit run wine_app/app.py
```

для streamlit community cloud укажите файл `wine_app/app.py` и python 3.12

подробнее о приложении и кешировании - в [wine_app/README.md](wine_app/README.md)
