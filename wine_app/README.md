приложение для оценки качества вина по сохраненной логистической регрессии

[открыть приложение](https://mmadhw3-cgrmqnwypngrcsngph9om9.streamlit.app/)

проверено на python 3.12.14. откройте терминал в папке `wine_app` и выполните:

```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

после запуска откройте локальный адрес, который появится в терминале

рядом с `app.py` должны лежать `model.joblib`, `config.json` и `test.csv`. модель обучена в ноутбуке, приложение только загружает ее и делает предсказания

на вкладке одного вина можно ввести признаки вручную. общий ползунок слева задает порог для одного вина, тестовых метрик и предсказаний из csv. в csv нужны все 12 столбцов признаков из `test.csv`, без `target`. результат можно скачать кнопкой под таблицей

модель загружается через `st.cache_resource`: это один общий объект, который не нужно копировать при каждом действии пользователя. таблица и тестовые вероятности используют `st.cache_data`, потому что это данные, для которых кеш возвращает копию результата. при изменении порога вероятности на тесте берутся из кеша, меняется только сравнение с порогом

если вызвать `joblib.load` без декоратора, модель будет читаться с диска при каждом перезапуске скрипта, в том числе при движении ползунка
